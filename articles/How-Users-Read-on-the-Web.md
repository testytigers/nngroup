<span class="article-summary-label">

Summary:&nbsp;

</span>They don&#x27;t. People rarely read Web pages word by word; instead, they scan the page, picking out individual words and sentences.

</div>

<div class="article-body">

<p>In <a href="/articles/applying-writing-guidelines-web-pages/"> research on how people read websites</a> we found that 79 percent of our test users always scanned any new page they came across; only 16 percent read word-by-word. (Update: a newer study found that <a href="/articles/e-mail-newsletters-usability"> users read email newsletters</a> even more abruptly than they read websites.)</p>

<p>As a result, Web pages have to employ <strong> scannable text</strong>, using</p>

<ul>

<li>highlighted <strong> keywords </strong> (hypertext links serve as one form of highlighting; typeface variations and color are others)</li>

<li>meaningful <strong> sub-headings </strong> (not "clever" ones)</li>

<li>bulleted <strong> lists </strong></li>

<li><strong>one idea </strong> per paragraph (users will skip over any additional ideas if they are not caught by the first few words in the paragraph)</li>

<li>the <a href="/articles/inverted-pyramids-in-cyberspace/"> inverted pyramid</a> style, starting with the conclusion</li>

<li><strong>half the word count </strong> (or less) than conventional writing</li>

</ul>

<p>We found that <strong> credibility is important </strong> for Web users, since it is unclear who is behind information on the Web and whether a page can be trusted. <a class="new" href="/articles/trust-or-bust-communicating-trustworthiness-in-web-design" title="Alertbox March 1999: Trust or Bust: Communicating Trustworthiness in Web Design"> Credibility can be increased</a> by high-quality graphics, good writing, and use of <strong> outbound hypertext links</strong>. Links to other sites show that the authors have done their homework and are not afraid to let readers visit other sites.</p>

<p>Users <strong> detested "marketese"</strong>; the promotional writing style with boastful subjective claims ("hottest ever") that currently is prevalent on the Web. Web users are busy: they want to get the straight facts. Also, credibility suffers when users clearly see that the site exaggerates.</p>

</div><h2 id="toc-measuring-the-effect-of-improved-web-writing-1">Measuring the Effect of Improved Web Writing</h2>

<p>To measure the effect of some of the content guidelines we had identified, we developed five different versions of the same website (same basic information; different wording; same site navigation). We then had users perform the same tasks with the different sites. As shown in the table, <a href="/articles/measuring-the-usability-of-reading-on-the-web/"> measured usability</a> was dramatically higher for the concise version (58% better) and for the scannable version (47% better). And when we combined three ideas for improved writing style into a single site, the result was truly stellar: <strong> 124% better usability</strong>.</p>

<p>It was somewhat surprising to us that usability was improved by a good deal in the objective language version (27% better). We had expected that users would like this version better than the promotional site (as indeed they did), but we thought that the performance metrics would have been the same for both kinds of language. As it turned out, our four performance measures (time, errors, memory, and site structure) were also better for the objective version than for the promotional version. Our conjecture to explain this finding is that <strong> promotional language imposes a cognitive burden </strong> on users who have to spend resources on filtering out the hyperbole to get at the facts. When people read a paragraph that starts "Nebraska is filled with internationally recognized attractions," their first reaction is <em> no, it's <strong> not</strong>, </em> and this thought slows them down and distracts them from using the site.</p>
