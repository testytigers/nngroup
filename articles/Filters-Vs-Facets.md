<span class="article-summary-label">

Summary:&nbsp;

</span>The terms “filters” and “faceted navigation” are often used interchangeably; although related, these concepts have important differences. Both tools help users narrow large sets of content, but faceted navigation — while more flexible and powerful — is more difficult to create and maintain.

</div>

<div class="article-body">

<p>Can you recall the last time you touched a physical phone book? We once relied on such tools as the only means of finding certain kinds of information. They were clunky and cumbersome, but when looking for a needle in a haystack—one phone number among thousands—they were essentially our only hope. In physical media, a single piece of information could be placed in only one location at a time, so providing access to many such objects required a static organization system describing the exact location of each item.</p>

<p>Direct access to digital information has completely changed the rules, <a href="https://www.nngroup.com/articles/better-than-reality-a-fundamental-internet-principle/">so we can now be "better than reality"</a> with search boxes, users can jump directly to whatever they are interested in, without consulting any complex systems. This instant gratification is a vast improvement over the previous methods of flipping through physical pages. But the spread of digital access to information has been accompanied by an explosion in the volume of information available about any given topic, to the extent that even instant access via search doesn’t necessarily make finding our needle in the haystack any easier.</p>

</div><h2 id="toc-filters-vs-facets-1">Filters vs. Facets</h2>

<p>Fortunately many websites now provide even more sophisticated tools to help users find information. <strong>Filters</strong> are one such tool — they analyze a given set of content to exclude items that don’t meet certain criteria. More recently, rich information systems have also begun to provide <strong>faceted navigation, </strong>which basically extends the idea of filters even further into a complex structure that attempts to describe all the different aspects of an object, for maximum flexibility in information retrieval.</p>

<p>These two terms —<em> filters </em>and <em>faceted navigation — </em>are sometimes used interchangeably. There is in fact quite a lot of overlap between these concepts: they share the same basic mechanism of <strong>analyzing a large set of content and excluding any objects that don’t meet certain criteria</strong>. The difference between the two is essentially one of degree, but it is an important difference. Ideally <strong>faceted navigation provides multiple filters</strong>, one for each different aspect of the content. Faceted navigation is thus more flexible and more useful than systems which provide only one or two different types of filters, especially for extremely large content sets. Because faceted navigation describes many different dimensions of the content, it also provides a structure to help users understand the content space, and give them ideas about what is available and how to search for it.</p>

<figure class="caption"><img alt="Venn diagram showing faceted navigation as a subset of filters" height="376" loading="lazy" src="//s3.amazonaws.com/media.nngroup.com/media/editor/2014/03/14/venn%20diagram.png" width="400"/>

<figcaption><em><strong>Filter</strong> means anything that analyzes a set of content and excludes some items. <strong>Faceted navigation</strong></em> <em>is composed of multiple filters that comprehensively describe a set of content. </em></figcaption>

</figure>

<p>For example, imagine searching for a healthy recipe for green enchiladas. Cooks.com has hundreds of green enchilada recipes. But in the absence of any filters, it’s difficult to find a healthy recipe, unless there happens to be a recipe with the word "healthy" in the recipe title. (In this case, no such luck.)</p>

<figure class="caption"><img alt='Screenshot of search results for "green enchiladas" on Cooks.com' height="510" loading="lazy" src="//s3.amazonaws.com/media.nngroup.com/media/editor/2014/03/13/cooks.com%20no%20filters%20green%20enchiladas.png" style="border-style:solid; border-width:1px" width="720"/>

<figcaption><em>The Cooks.com website has many recipes for enchiladas but no filters to help distinguish between these recipes.</em></figcaption>

</figure>

<p>Basic search filters like the tabs on Food.com can help users narrow down large sets of search results, but only if the filters actually match the dimensions that are most important to users. On Food.com, the tabs filter by the type of content — recipes, photos, cookbooks, etc. — so in this case they wouldn’t be helpful.</p>

<figure class="caption"><img alt='Screenshot of search results for "green enchiladas" on Food.com' height="523" loading="lazy" src="//s3.amazonaws.com/media.nngroup.com/media/editor/2014/03/13/food.com%20filters%20green%20enchiladas.png" style="border-style:solid; border-width:1px" width="720"/>

<figcaption><em>Basic tabs on Food.com allow users to filter search results by format (for example: </em>Recipes, Photos, Cookbooks).</figcaption>

</figure>

<p>In contrast, the full-fledged faceted navigation on Epicurious.com allows users to narrow results by several different dimensions, including <em>Cuisine, Main Ingredient, </em>and <em>Dietary Consideration.</em> In this case it’s a simple matter to view only healthy recipes.</p>

<figure class="caption"><img alt='Screenshot of search results for "green enchiladas" on Epicurious.com' height="634" loading="lazy" src="//s3.amazonaws.com/media.nngroup.com/media/editor/2014/03/13/epicurious%20facets%20green%20enchiladas.png" style="border-style:solid; border-width:1px" width="720"/>

<figcaption><em>The faceted navigation on Epicurious.com allows the flexibility to narrow results by many different criteria, including </em>Main Ingredient, Cuisine, <em>and </em>Dietary Consideration.</figcaption>

</figure>

<p>Although the faceted navigation system has obvious benefits for end users, this type of structure is significantly more expensive to create and maintain; more resources must be invested in designing the user interface, and both existing and future content must have metadata applied for each facet.</p>

<p>The extra power of faceted navigation also adds <a href="https://www.nngroup.com/articles/interaction-cost-definition/">interaction cost</a> by presenting users with more options to comprehend and manipulate. A simple filter can often be easier to understand and faster to use.</p>

<p>For these reasons it’s wise to make sure that users truly do need faceted navigation in order to use your content effectively, before investing in it.</p>
